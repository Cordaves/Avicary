Schnelle Computer-Hilfe

Sichere Bildschirm-Hilfe über die eingebaute Windows-Funktion – ohne Download und ohne Installation.

Hinweis: Sie öffnen diese Seite gerade auf einem Handy oder Tablet.
Bitte öffnen Sie diesen Link am Windows-Computer bzw. Notebook, damit die Remotehilfe direkt starten kann.
Hinweis: Diese Seite wurde nicht auf einem Windows-Computer geöffnet. Die eingebaute Windows-Remotehilfe funktioniert nur unter Windows 10 oder Windows 11. Unten können Sie trotzdem den kurzen Geräte-Check kopieren.
Remotehilfe starten
  1. 1
    Klicken Sie oben auf „Remotehilfe starten“.
  2. 2
    Ihr Browser fragt kurz „Remotehilfe öffnen?“ – klicken Sie dort auf „Öffnen“.
  3. 3
    Tippen Sie den 6-stelligen Code ein, den ich Ihnen am Telefon sage, und bestätigen Sie mit „Zulassen“.
Sicher & transparent: Sie sehen die ganze Zeit alles auf Ihrem Bildschirm mit und können die Verbindung jederzeit sofort beenden. Es wird nichts dauerhaft installiert.
Falls sich beim Klicken nichts öffnet

Möglichkeit 1 (Tastatur): Drücken Sie gleichzeitig Windows-Taste + Strg + Q.

Möglichkeit 2 (Startmenü): Drücken Sie die Windows-Taste, tippen Sie Remotehilfe ein und drücken Sie Enter.

Möglichkeit 3 (Update aus dem Microsoft Store): Falls Windows meldet, dass die App fehlt oder aktualisiert werden muss, öffnen Sie sie direkt im offiziellen Microsoft Store:
